The first release of zmural: live wallpapers (videos, pictures and animated GIFs) for Windows 11 and Linux Wayland desktops, from one codebase.

**This is an early pre-release.** It's used day to day on both operating systems, but it has had little time on desktops other than the developer's. Please report what breaks.

## Download

| | File | Then |
|---|---|---|
| **Windows 11** (x86-64) | `zmural-0.1.0-windows-x86_64.zip` | Unzip it somewhere it can stay (for example `%LOCALAPPDATA%\Programs\zmural`) and run `zmural.exe`. Everything it needs is inside. |
| **Linux** (x86-64, Wayland) | `zmural-0.1.0-linux-x86_64.tar.gz` | Extract it (for example to `~/.local/opt/zmural`), install mpv, Mesa, Pango and Cairo from your package manager ([one line per distro](https://github.com/AstraLibernis/zmural#install)), and run `bin/zmural`. |

There is no installer. On first run zmural adds itself to your app menu and to start at login, and on KDE Plasma and GNOME it sets up its own wallpaper plugin or extension. **Uninstall** on the settings window's General page (or `zmural-console uninstall`) removes all of that again; then delete the folder.

Linux needs KDE Plasma 6 (Qt 6.8+), GNOME 48–51, or Sway, Hyprland, labwc, Wayfire, Niri or COSMIC. On GNOME, log out and back in once after the first run. See [What you need](https://github.com/AstraLibernis/zmural#what-you-need).

## What's in it

- Videos, pictures and animated GIFs as wallpaper, decoded on the GPU where your system can
- A library from your `Wallpapers` folders, with rotation (in order, shuffled or random)
- A different wallpaper and fill mode per monitor
- Speed, brightness, contrast, saturation, gamma and hue adjustments, per wallpaper
- Automatic pausing for games and fullscreen apps, a locked screen, battery and more, each rule configurable
- `.zip` wallpaper packages, import and export, including Lively Wallpaper packages
- A settings window, a tray icon, and `zmural-console` for the terminal
- Web-page wallpapers (local pages, always offline): **Windows only** so far

## Known limitations

- **Not code-signed:** Windows SmartScreen may warn before the first run.
- **No updater:** to update, quit zmural and unpack the new release over the old folder.
- **Multiple monitors** are tested only with virtual screens on Linux, not on real hardware.
- **Screen readers** can't read the settings window; `zmural-console` does everything it does.
- **Video and image renderers aren't sandboxed yet.** The full list is in the README's [Security](https://github.com/AstraLibernis/zmural#security) section.

## Reporting a crash

After a crash zmural shows a line like `zmural 0.1.0 linux crash: 1216a76 10fab48`. Please include that line and your `zmural.log` (Windows `%LOCALAPPDATA%\zmural\zmural.log`, Linux `~/.local/state/zmural/zmural.log`) in an issue. The `*-debug.zip` and `*-debug.tar.gz` files turn those addresses into source lines; you don't need them to run zmural.
