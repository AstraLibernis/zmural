Fixes from the first public test of zmural: someone who had never seen it downloaded 0.1.0, used every part of it, and uninstalled it. Everything they found that didn't work, or didn't say what it did, is fixed here.

**This is still an early pre-release.** Download and install exactly as for [0.1.0](https://github.com/AstraLibernis/zmural/releases/tag/v0.1.0): unpack it over the old folder after quitting zmural; your settings and library are kept.

## Fixed

- **Sway: right-clicking the tray icon did nothing.** Sway's bar can't show an app's menu, so a right click there now opens the settings window, whose player card has pause, mute, next and previous. Other desktops keep the quick menu.
- **Zip bombs.** A 3 MB zip that unpacked to 3 GiB was imported. A zip may now unpack to 4 GiB at most, and past 256 MiB to no more than 20 times its own size (real wallpapers are far from it).
- **Buttons that did nothing.** Open (a library folder), Log file > Open and Show in folder now say so, with the path, when nothing on the desktop could open it.
- **Uninstall from the settings window** paused for about 5 seconds on a half-drawn question; it is now immediate.
- **`zmural-console apply` of a file that can't play** reported success; it now fails with the reason.
- **`zmural-console export <name>`** takes a wallpaper's name from the library, not only a path.
- **"You won't be told again"** about a video format played on the CPU now holds.
- **The player card** said "Playing" while a pause rule (a window covering the desktop, a game) held the wallpaper; it says which rule now.
- **Two wallpapers with the same name** (a zip imported twice) show their folders: "sun.png · Sunsets (2)".
- **A hand edit to settings.toml zmural can't use** was only logged; a notification now says which line.
- The log no longer notes the library every few seconds.
- Docs: the Welcome page no longer offers web pages on Linux (Windows-only so far); install examples, a Troubleshooting entry for Linux file pickers, and the packages' READMEs list every command.

## Tested

Every button and menu in the settings window is now pressed by an automated test with a real (virtual) mouse on Linux, and the tray is clicked on Sway's bar; a soak test runs a day of use in rounds and checks that memory, open files and processes stay flat. On Windows, CI builds and runs the zip, and the release is checked by hand on a Windows 11 desktop before it is published.

## Known limitations

As in 0.1.0: not code-signed (SmartScreen may warn), no updater, multiple monitors tested only on virtual screens, no screen-reader support in the settings window, video and picture renderers not yet sandboxed. See the README's [Security](https://github.com/AstraLibernis/zmural#security) section.

## Reporting a crash

After a crash zmural shows a line like `zmural 0.1.1 linux crash: 1216a76 10fab48`. Please include that line and your `zmural.log` (Windows `%LOCALAPPDATA%\zmural\zmural.log`, Linux `~/.local/state/zmural/zmural.log`) in an issue. The `*-debug.zip` and `*-debug.tar.gz` files turn those addresses into source lines; you don't need them to run zmural.
