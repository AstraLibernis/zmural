# notes/

Dated working notes from zmural's development: research on the projects it learned from
(Lively, waywallen), audits, test reports from real and headless desktops, and the
"stopping point" handover written at the end of each working day.

They are a log, not documentation. Each note was true on its date and is kept as written,
so later notes and the code win where they disagree; [docs/](../docs) is the current
state. Development before 2026-10-12 happened in a private repository, so commit IDs and
remarks about the repository being private refer to that time. "The owner" is the
project's maintainer.
