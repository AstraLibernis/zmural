# Feature parity: zmural against Lively and waywallen (2026-09-30)

What the two best free live-wallpaper managers can do that zmural can't yet, and the reverse.

**Where each column comes from**
- **Lively** (Windows) and **waywallen** (Linux): read from their source, in `notes/lively.md`
  (HEAD `6dab5a6`) and `notes/waywallen.md` (v0.4.3). A feature they gained since is not here.
- **zmural**: the code on `main` today, checked against `docs/MILESTONES.md`; "W" is Windows,
  "L" is Linux. A tick means it works there, not that it is planned.
- Not compared in depth, from their own pages only: **ScreenPlay** (Qt, Windows and macOS,
  still alpha, Linux "planned"), **Hidamari** and **mpvpaper** (Linux video wallpapers, far
  fewer features), and Wallpaper Engine (not free).

## Reading it

**Where zmural is already level or ahead:** the pause rules (the widest set of the three, with
an action per rule), rotation (Lively has none), running on both OSes from one codebase, the
command line on Linux, safer web wallpapers (offline by default, one origin and profile per
wallpaper, no debugger attach), and crash containment.

**The gaps a user would notice first, most noticeable first:**
1. **One wallpaper for all monitors.** Both others do per-monitor. This was listed as done in
   the M5 summary row; it wasn't. *Done later the same day* (command line and file; the
   window's picker, span and per-monitor fill remain).
2. **No way to change a wallpaper's properties from the window** (the Customise panel), and no
   video adjustments.
3. **No mouse interaction**, no audio-reactive wallpapers, no now-playing or system stats.
4. **Linux has no web wallpapers.**
5. **No packages or importing** (`.zip`, Lively's format), no search or tags.
6. **No transitions, no blur while paused, no screensaver.**
7. **Distribution:** no installer on Windows beyond a zip, nothing packaged on Linux, no updates.
8. English only.

**Deliberately not matched:** programs as wallpapers and YouTube streams (both run untrusted
things with the user's rights), third-party renderers and plugins (waywallen's; owner's
decision 2026-09-30, see "How zmural is put together" in `docs/MILESTONES.md`), web addresses
as wallpapers and any network access for a page (same decision), taskbar theming and the other Lively desktop tweaks, ML depth
wallpapers, an account-based gallery.
